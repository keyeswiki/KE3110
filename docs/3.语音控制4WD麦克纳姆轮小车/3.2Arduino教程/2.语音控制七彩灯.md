### 第2课 语音控制七彩灯

#### 2.1 课程介绍

使用语音识别模块接收到的语音指令来控制4WD麦克纳姆轮智能小车上的两个七彩灯，用户只需说出 “请开灯” 或 “请关灯” 等指令，系统便能快速响应，实现精准的本地化控制，可以使两个七彩灯点亮或熄灭。这意味着以后你可以轻松地将语音控制功能添加到任何项目中，比如语音控制智能小车或语音播报距离。

#### 2.4 实验代码

⚠️ <span style="color:red;">**特别提醒：语音控制 4WD 麦克纳姆轮小车已经组装好了。由于不需要用到蓝牙模块，那么在上传代码之前，请务必拔掉蓝牙模块。因为蓝牙模块也占用Arduino的串口通信（TX/RX），如果不拔掉，代码上传会失败！！**</span>

```cpp
// 导入相关库文件
#include <SoftwareSerial.h>
#include "MecanumCar_v2.h"

/*******智能语音识别模块接口*****/
const int RX_PIN = A5; // 引脚 A5 为 RX
const int TX_PIN = A4; // 引脚 A4 为 TX
SoftwareSerial mySerial(RX_PIN, TX_PIN); // 定义软件串口引脚（RX, TX）

/*******七彩灯与4个电机接口*****/
mecanumCar mecanumCar(3, 2); // sda-->D3，scl-->D2

// 定义变量用于存储从语音模块接收到的控制码
volatile int Voice_Control = 0;  // 初始化为0，确保首次判断时不触发任何指令

void setup() {
  Serial.begin(9600);  // 硬件串口（与电脑通信）
  mySerial.begin(9600);  // 软件串口（与外设通信）
  mecanumCar.Init();  // 初始化电机与七彩灯驱动
}

void loop() {
  if (mySerial.available()) {  // 检查软串口是否有来自语音模块的数据可读
     Voice_Control = mySerial.read();  // 从软串口读取多个字节的数据      
     Serial.println(Voice_Control);  // 将接收到的数据通过硬件串口输出到串口监视器，便于调试
  }
  if (Voice_Control == 1) {  // 根据接收到的指令值1，执行相应操作
     mecanumCar.left_led(1);  // 开启左边七彩灯闪烁
     mecanumCar.right_led(1); // 开启右边七彩灯闪烁
  } else if (Voice_Control == 2) {  // 根据接收到的指令值2，执行相应操作
    mecanumCar.left_led(0);  // 关闭左边七彩灯闪烁   
    mecanumCar.right_led(0); // 关闭右边七彩灯闪烁
  }
  // 清除指令，避免重复执行
  Voice_Control = 0;
}
```

#### 2.5 代码解释

1\. 引入库与定义引脚

```cpp
#include <SoftwareSerial.h>
#include "MecanumCar_v2.h"
const int RX_PIN = A5; // 引脚 A5 为 RX
const int TX_PIN = A4; // 引脚 A4 为 TX
SoftwareSerial mySerial(RX_PIN, TX_PIN); 

mecanumCar mecanumCar(3, 2);  //sda-->D3,scl-->D2
```
引入了 `SoftwareSerial` 库，因为它允许在任意数字引脚上模拟串口通信。`SoftwareSerial mySerial(RX_PIN, TX_PIN)` 表示 A5 作为 RX（接收），A4 作为 TX（发送）。这解决了 Arduino UNO 只有一个硬件串口且被 USB 占用的问题。
同时 `mecanumCar mecanumCar(3, 2)` 表示 SDA 引脚接D3，SCL引脚接D2。

2\. Setup 初始化

```cpp
Serial.begin(9600);
mySerial.begin(9600);
```
这里设置的波特率 `9600` 必须与硬件串口（与电脑通信）和 软件串口（与智能语音识别模块内部的设置）完全一致。如果七彩灯没反应，首先要怀疑的就是波特率不对。

3\. Loop 中的数据处理

```cpp
if (mySerial.available()) {  
   Voice_Control = mySerial.read();     
   Serial.println(Voice_Control); 
}
```

`mySerial.available()` 检查是否有数据到达。如果有，`read()` 读取一个字节。语音识别模块发送的通常是一帧数据（如 6 个字节），但在简单实验中，我们往往可以通过识别其中的特征字节（如命令码）来判断。

4\. 七彩灯状态控制函数

```cpp
if (Voice_Control == 1) { 
   mecanumCar.left_led(1); 
   mecanumCar.right_led(1); 
} else if (Voice_Control == 2) { 
   mecanumCar.left_led(0);   
   mecanumCar.right_led(0); 
}
```
如果语音识别模块接收到 “请开灯” 等命令词(命令码为1)时，七彩灯点亮；如果语音识别模块接收到 “请关灯” 等命令词(命令码为2)时，七彩灯熄灭。

#### 2.6 实验结果

⚠️ <span style="color:red;">**重要提示：由于不需要用到蓝牙模块，那么在上传代码之前，请务必拔掉蓝牙模块。因为蓝牙模块也占用Arduino的串口通信（TX/RX），如果不拔掉，代码上传会失败！！**</span>

外接电源，将电机驱动板上的拨码开关拨到 “<span style="color: rgb(255, 76, 65);">ON</span>” 端，上电后。选择好正确的开发板板型（Arduino Uno）和 适当的串口端口（COMxx），然后单击 ![Img](../../media/cou0.png) 按钮上传代码至Arduino控制板。

代码上传成功后，然后对着语音识别模块上的麦克风，使用唤醒词 “你好，小智” 或 “小智小智” 来唤醒语音识别模块，同时喇叭播放回复语 “有什么可以帮到您”；

语音识别模块唤醒后，对着麦克风说：“请开灯” 等命令词时，喇叭播放对应的回复语 “已为您打开照明”，同时七彩灯点亮。

对着麦克风说：“请关灯” 等命令词时，喇叭播放对应的回复语 “已为您关闭照明”，同时七彩灯熄灭。
