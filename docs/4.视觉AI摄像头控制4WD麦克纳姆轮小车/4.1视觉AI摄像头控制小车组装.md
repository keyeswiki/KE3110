4.2 视觉AI摄像头模块接线

⚠️ <span style="color:red;">**特别提醒：接线时，请注意区分线材颜色、端口正反面，请勿反插，否则会损坏端口。线材的一头卡口端口与视觉AI摄像头模块连接，另一头端口再接到扩展板上，G通过黑线接G，V通过红线接V，TX通过橙线接A4，RX通过白线接A5。**</span>

| 视觉AI摄像头模块（UART口） |  扩展板 | 
| :---: | :---: |
| **黑线（G）** | G | 
| **红线（V）** | 5V | 
| **橙线（TX）** | A4 |
| **白线（RX）** | A5 |
