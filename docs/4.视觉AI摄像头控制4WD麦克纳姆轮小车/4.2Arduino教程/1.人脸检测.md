### 第1课 人脸检测

#### 1.1 课程介绍

这节课我们将使用 4WD 麦克纳姆轮小车与视觉AI摄像头搭配使用实现人脸检测功能；当识别到人脸时，4WD 麦克纳姆轮小车上的两个七彩灯就闪烁，否则七彩灯不亮。

#### 1.2 视觉AI摄像头简介

视觉AI摄像头是一款基于ESP32-S3 N16R8模组打造的多功能AI摄像头，搭载专属内置固件，可稳定实现人脸检测、颜色识别、二维码识别、卡片识别等多种智能视觉功能。硬件方面，设备配备两个MX1.25接口，分别引出IIC与UART通信接口；支持接入TF卡拓展存储空间，同时板载BOOT按键与RESET复位按键，操作与拓展性更强。设备搭载1.54英寸TFT彩色显示屏，可清晰地实时显示摄像头拍摄画面。机身底部预留5个乐高安装孔，能够兼容乐高配件，可灵活完成结构拓展与组装适配。

#### 1.3 视觉AI摄像头参数

- 输入电压：DC3.3V 或 DC5V
- 平均工作电流：175 mA
- 连接器端口：MX1.25-4P
- 工作温度范围：0-50℃
- 尺寸：57mm×59mm×20mm
- 环保属性：ROHS

#### 1.6 实验代码

⚠️ <span style="color:red;">**特别提醒：视觉AI摄像头控制 4WD 麦克纳姆轮小车已经组装好了。由于不需要用到蓝牙模块，那么在上传代码之前，请务必拔掉蓝牙模块。因为蓝牙模块也占用Arduino的串口通信（TX/RX），如果不拔掉，代码上传会失败！！**</span>

```C
// 导入库文件
#include <Arduino.h>
#include "AiCam.h"
#include <MecanumCar_v2.h>

AiCam aiCam(A4, A5); // 定义引脚: TX接A4,RX接A5
mecanumCar mecanumCar(3, 2); // 定义引脚: SDA接D3,SCL接D2

void setup() {
   Serial.begin(115200); // 设置波特率为115200
   aiCam.begin(); // 启动视觉AI摄像头
   mecanumCar.Init();  // 初始化电机与七彩灯驱动

   aiCam.setAiCamMode("face"); // 设置视觉AI摄像头为为人脸识别模式
}

void loop() {
   aiCam.readEspSerial(); // 持续读取摄像头串口数据，刷新识别缓存
   if (aiCam.getFaceX() != 0 && aiCam.getFaceY() != 0)  { // 视觉AI摄像头识别人脸
      mecanumCar.left_led(1);  // 开启左边七彩灯闪烁
      mecanumCar.right_led(1); // 开启右边七彩灯闪烁
   } else {
      mecanumCar.left_led(0);  // 关闭左边七彩灯闪烁   
      mecanumCar.right_led(0); // 关闭右边七彩灯闪烁
   }
   delay(50);  // 新增延时，50毫秒刷新一次状态
}
```

#### 1.7 代码说明

1\. 导入库文件和引脚定义

```c
#include <Arduino.h>
#include "AiCam.h"
#include <MecanumCar_v2.h>

AiCam aiCam(A4, A5); 
mecanumCar mecanumCar(3, 2); 
```
- 导入相关的库文件，定义视觉AI摄像头模块的引脚TX接A4、RX接A5，定义4个电机的引脚SDA接D3,SCL接D2

2\. setup()初始化函数 

```c
void setup() {
   Serial.begin(115200); 
   aiCam.begin(); 
   mecanumCar.Init();  

   aiCam.setAiCamMode("face"); // 设置视觉AI摄像头识别模式为人脸识别
}
```
- 初始化波特率为115200，启动视觉AI摄像头，并且切换模式为人脸识别;

- 初始化电机与七彩灯驱动。

3\. loop()主循环函数

```c
void loop() {
   aiCam.readEspSerial();
   if (aiCam.getFaceX() != 0 && aiCam.getFaceY() != 0) { 
      mecanumCar.left_led(1);  
      mecanumCar.right_led(1); 
   } else {
      mecanumCar.left_led(0);   
      mecanumCar.right_led(0); 
   }
   delay(50);  
}
```
- 在无限循环中读取视觉串口数据，并且通过判断视觉AI摄像头是否检测到人脸。如果检测到了，那么两个七彩灯闪烁；否则，七彩灯不亮。同时延时0.05秒。

#### 1.9 常见问题

1\. 如果视觉AI摄像头模块屏幕闪烁，或智能车持续复位且无法正常工作：

- 解决方案：检查电池电量是否过低或电池质量是否不佳。电源可能已无法为智能车和视觉AI摄像头模块提供足够的电力。
